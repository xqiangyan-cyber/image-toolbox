# 图片小工具箱（免费静态网站）

## 功能
- 浏览器端 AI 背景移除（依赖 @imgly/background-removal 开源包及其模型文件，首次使用需联网下载）
- 添加文字水印
- 基础局部模糊处理
- 图片尺寸调整
- 撤销、恢复原图、PNG 下载

## 免费部署：GitHub Pages
1. 注册/登录 GitHub。
2. 新建一个公开仓库，例如 `image-toolbox`。
3. 将 `index.html` 上传到仓库根目录。
4. 打开仓库 Settings → Pages。
5. 在 Build and deployment 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/ (root)`，点击 Save。
7. 等待发布完成，GitHub Pages 会给出公开网址。

## 重要说明
- 这是无需后端的静态网页，图片编辑操作默认在用户浏览器内进行。
- AI 抠图需要联网下载模型，模型较大，首次打开可能较慢；不同浏览器/设备效果和速度不同。
- “局部修复”是基础模糊覆盖，不是生成式无痕修复，也不保证能清除复杂背景上的水印。
- 仅处理自己拥有版权或已获授权的图片；不要用于去除版权、署名或来源标识。
- 本项目使用第三方开源库的 CDN 导入方式。正式公开运营前，请检查该库当前许可证、模型许可及其隐私/服务条款。
